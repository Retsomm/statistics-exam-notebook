# 國文與公民英文歷屆試題擴充

新增年度：97、98、99、100、101、102、103、104、105、112 年。

兩科各新增十份試卷，共二十份、905 道測驗題。每份試卷的官方原卷、答案、更正公告與 PDF SHA-256 指紋保存在 `data/common-bank-meta.json`；題目保存於 `data/papers`。PDF 僅於暫存目錄擷取文字，不提交原卷或掃描圖片。

97、98 年國文原卷包含作文、公文及十題測驗。網站只計算測驗部分，滿分為 20 分，並於試卷卡片及作答畫面標示；作文、公文保留官方原卷查閱方式。

新題的題幹、選項、閱讀題組與官方答案已匯入。官方更正包括可接受多個答案、單選題複數劃記給分、一律給分，以及未作答不給分等情況，分別保留 `accepted`、`correction` 和 `allCredit`，不推定或修改官方判定。

新試卷的逐題學習解析、完整白話翻譯及新增單字卡尚未撰寫。所有新試卷明確標記 `explanationStatus: pending`，不產生空泛解析或宣稱解析已完成。既有 1,665 題解析及收藏識別碼保留；既有成語詞條會連結新增試卷中出現的相同成語。

早期英文克漏字使用實際題組範圍，包括 102 年第 43 至 47 題、112 年第 46 至 50 題。閱讀測驗與克漏字分別標記，不依固定題號猜測題型。

來源準備流程僅在 `codex/common-paper-import` 分支下載及保存文字供檢視；正式題庫由匯入資料與既有題庫合併建置。匯入流程先執行 `fetch-sources.py`、`parse-sources.py`，核對後再以 `write-bank.py` 保存，最後執行測試、建置與桌面／手機作答測試。
