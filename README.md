# 統計研習所：初等考試統計類科題庫

這是一個使用 Next.js、Firebase Authentication 與 Firestore 建置的初等考試練習網站，正式網址為 https://statistics-exam-notebook.web.app/ 。

## 收錄內容

- 四科皆收錄十九個年度：97 至 115 年，統計學大意與資料處理大意已補齊相同年份。
- 全站共 76 份試卷、3,470 道測驗題；本次補入專業科目 97 至 105 年及 112 年，共 20 份試卷、900 題。
- 97、98 年國文僅收錄測驗部分（各十題、滿分 20 分）；作文與公文請參閱官方原卷。
- 新增 900 題均有逐題解題步驟及四個選項的具體理由，依官方更正公告計分；爭議題保留官方計分，另說明正確定義、版本條件或題目缺漏，不編造支持官方答案的理由。
- 國文與公民英文，以及統計類科兩個專業科目：統計學大意、資料處理大意。
- 統計學大意每年 40 題、每題 2.5 分；資料處理大意每年 50 題、每題 2 分。
- 每題保留考選部官方原卷、標準答案與查詢頁連結。公式、表格、圖表或程式碼排版以官方原卷為準。
- 作答、錯題本、收藏、筆記、解析收藏、訪客備份與 Google 登入同步。

新增專業試卷的來源雜湊、逐題審閱與驗算方式見 `PROFESSIONAL_REVIEW.md`。

題目與答案來源為考選部考畢試題查詢平臺：https://wwwq.moex.gov.tw/exam/wFrmExamQandASearch.aspx 。

## 本機執行

```bash
npm ci
npm run dev
```

檢查與建置：

```bash
npm test
npm run build
```

每次推送 `main` 時，GitHub Actions 會執行測試、建置及 Firebase Hosting 部署。

### 個人中心

主要導覽保留學習總覽、歷屆題庫、模擬考與個人中心。原「備份與資料」改為個人中心，內含學習看板、重點整理、收藏與錯題、備份與資料四個分頁；原有匯入、匯出、回報紀錄與帳戶操作保留。

看板提供連續／最長造訪天數、今日及近七天作答量與正確率、近十四天趨勢、可切換月份的造訪日曆與每日科目明細。統一以臺灣日期（Asia/Taipei）分組，同一天重練算不同次作答，完成的模擬考只在交卷當天計入已填答題目，不把空白或未交卷計入。正確率以完全答對計算，與國文複選題的部分分數不同。歷史統計依目前保留的作答與交卷紀錄計算，沒有紀錄時顯示空畫面。

造訪從本功能上線後開始記錄，不依舊作答紀錄回推未保存的造訪日期。同一臺灣日期只記一次；分頁顯示期間跨日或重新開啟時會檢查日期。登入者的日期以交易合併至私有的 `users/{uid}/study/activity`，與舊版練習中繼資料分開，舊分頁不會覆蓋造訪紀錄。訪客保存在目前瀏覽器。備份可保存、還原與合併日期，既有 `yueri:*` 鍵及待同步佇列維持相容。

### 模擬考

「模擬考」依 116 年官方日程，可自由選擇國文、公民與英文、資料處理大意或統計學大意單獨應試，每科 60 分鐘。每次單科獨立成回，交卷後可立即重考同科或換科，不必完成四科；舊四科回合仍可檢視與接續，未開始科目不會擋住新模擬考。題數與配分依目前收錄的最新年度試卷；歷年題目混合抽出，國文保留 35 題單選、10 題複選，公民與英文保留 35／15 題，英文採歷年真實試卷的單題、克漏字及閱讀題組配置，整組抽取且組內依原題號連續排列，先單題再題組；3、4、5 題題組皆不拆分。專業科目使用最新每題配分。每科先抽未曾在模擬考出現的題目，不足才補已出現題目；完整覆蓋該科題庫後才從全題庫隨機抽題。各科會依共用題幹及「承上題／上題／承上兩題」關係合併連動題，前題、後題與連鎖題整組抽取並依原題號連續出現；採整組配額計算，維持國文單選／複選配分、公民／英文比例及各科題數，並優先最大化尚未出現的題目。開始該科時記錄出題覆蓋，日常練習不影響。

選項、進度與開始時間即時保存。倒數以開始時間加上 60 分鐘的絕對期限計算，換頁不暫停；瀏覽器關閉期間無法執行程式，重開時依原期限自動結算。選完所有題目後按「保存並下一題」立即結算，亦可提前交卷；交卷後的成績、答案、用時與剩餘時間不再被舊裝置的未完成進度覆蓋。單科分數不直接與歷年錄取總平均比較。累積四個不同科目的已交卷成績後，提供各科最近一次成績的跨次參考平均，明確區別於同回四科平均；平均取小數點後二位，第三位四捨五入。

「重置模擬考分數」只作用於目前帳戶或訪客的模擬考，清除成績、作答與計時結果，保留一般學習資料和出題覆蓋率。每回保留 `resetAt` 標記，已重置的成績不會被舊裝置、離線重試或舊備份恢復。

每回紀錄獨立保存在登入帳戶的 `users/{uid}/study/mock-{uuid}` 文件，與既有本機備份、離線佇列及匯入／匯出整合，不截斷模擬考歷史。訪客僅存目前瀏覽器；登入後才有雲端同步。每次新增寫入路徑需一併部署 `firestore.rules`。

106–115 年統計類科錄取標準及 116 年考試時間的查核資料在 `data/mock-exam-reference.json`，包含考選部直接來源、原表統計列及原檔 SHA-256；不提交官方 PDF。錄取標準是各年四科總平均，僅供回顧比較。官方計分規則見該檔中的 `scoringSource` 與 `eligibilitySource`。

規則部署使用專案自訂角色 `projects/library-exam-notebook/roles/githubFirestoreRulesDeployer`，授予既有 GitHub Actions 部署服務帳戶。此角色只包含以下六項規則部署與驗證權限，不包含刪除或專案管理權限，無須授予 Owner、Editor 或完整的 `roles/firebaserules.admin`：

```text
firebaserules.rulesets.create
firebaserules.rulesets.get
firebaserules.rulesets.test
firebaserules.releases.get
firebaserules.releases.list
firebaserules.releases.update
```

`Deploy Firestore Rules` 會在 `main` 的 `firestore.rules`、規則測試或該工作流程變更時先執行模擬器測試，再發布規則；同類新資料路徑可沿用這項持續性授權。Hosting 成功不代表 Firestore 規則已更新，仍須確認規則部署工作流程成功。若 Rules API 回傳 403，先核對上述自訂角色及其服務帳戶綁定，再重跑「Deploy Firestore Rules」。規則未開通時，前端仍保留既有練習功能，模擬考資料先保留於本機與待同步佇列，並顯示同步失敗提示；不可宣稱已完成跨裝置保存。
